## 📌 Project Overview

The AI Learning Portal provides two primary experiences:

### Teachers

Teachers can manage their courses and monitor student performance through:

* Course creation and management
* Modules and topics
* Course materials

  * Videos
  * Slides
  * Notes
  * Exercises
  * Practice tests
* Student enrollment management
* Attendance tracking
* Grade management
* Automatically calculated course grades
* Student and class performance analytics
* Weak-topic identification
* AI-generated review and intervention recommendations

### Students

Students can use the portal to:

* View enrolled courses
* Browse course modules and materials
* Track material completion
* Complete exercises and practice tests
* View grades
* View attendance
* Track course progress
* Identify weak topics
* Receive AI-generated study recommendations and study plans

## 🤖 AI Integration

### Student AI Features

Students can receive:

* Study recommendations
* Personalized study plans
* Suggested topics to review
* Suggested study/homework actions

### Teacher AI Features

Teachers can receive:

* Suggested review topics
* Class-level performance insights
* Potential student interventions
* Recommendations based on attendance and academic performance
